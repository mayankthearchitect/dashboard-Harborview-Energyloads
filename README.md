# Harborview Tower - Energy Load Profiles Dashboard

An interactive dashboard for visualizing and analyzing heating and cooling load data for Harborview Tower.

## Features

- **Real-time Statistics**: View peak and average heating/cooling loads
- **Interactive Charts**: Line, bar, and area chart options
- **Date Range Filtering**: Analyze specific time periods (weeks, months, quarters, seasons)
- **Seasonal Analysis**: Scatter plot with color-coded seasonal data
- **Responsive Design**: Works on all screen sizes
- **Dark Theme**: Professional dark UI matching industry standards

## Live Demo

[View Dashboard](https://yourusername.github.io/repository-name/)

## Data

The dashboard displays a full year of hourly energy load data (8,760 data points), including:
- Heating Load (kBtu/h)
- Cooling Load (kBtu/h)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js for data visualization
- Papa Parse for CSV processing

## Local Development

To run locally:

1. Clone the repository
2. Navigate to the project directory
3. Start a local server:
   ```bash
   python3 -m http.server 8000
   ```
4. Open your browser to `http://localhost:8000`
